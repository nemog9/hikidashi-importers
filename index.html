Hikidashi Importers
iPhone の Safari 用

購入履歴を、CSV にして
Hikidashi に取り込む。

自分のアカウントの購入履歴を、自分のブラウザの中だけで、CSV にするスクリプトです。サーバーには何も送りません。

スクリプト

下のボタンを Safari で開くと、Userscripts が「インストール」を案内します（先に、下の準備を済ませてください）。

DMM（FANZA）マイライブラリ

購入済みの同人作品（ボイス・コミック・CG）を、タイトル・URL・クリエイター・画像つきで CSV にします。

インストール 対象ページ: www.dmm.co.jp/dc/-/mylibrary/　・v0.4.1

DLsite 購入履歴

購入履歴の作品を、声優・サークル・カテゴリ・画像つきで CSV にします。負荷をかけないよう、間隔を空けて読み、続きから再開できます。

インストール 対象ページ: www.dlsite.com/*/mypage/userbuy　・v0.1.1

使いかた

  1. Userscripts アプリを入れて、保存フォルダを選ぶ

    App Store で「Userscripts」（無料）を入れ、一度開いて、スクリプトの保存先フォルダを選びます（「ファイル」の「このiPhone内」に新しいフォルダを作ると簡単です）。

  2. Safari で使えるようにする（ここでつまずきやすい）
    • 設定 → アプリ → Safari → 機能拡張 → Userscripts →「拡張機能を許可」をオン。
    • 同じ画面で「他の Web サイト」を「許可」にする（対象サイトだけでもよい）。
    • プライベートブラウズではなく、通常のタブで開く。
  3. スクリプトを入れる

    上のボタンを Safari で開いて、「インストール」をタップします。

  4. サイトを開いて、書き出す

    DMM のマイライブラリ、または DLsite の購入履歴を、ログインした状態で開きます。画面に出るパネルで「全件を取得」を押し、終わったら「CSV を保存」または「共有…」で保存します。

  5. Hikidashi に取り込む

    Hikidashi の「設定 → CSV をインポート」で、保存した CSV を選びます。同じ作品は URL で見分けるので、何度取り込んでも重複しません。

お約束と注意

非公式のツールです。DMM／FANZA・DLsite・Hikidashi の運営とは関係がありません。

自分のアカウントの、自分の購入履歴を、自分のブラウザの中だけで処理します。パスワードやトークンは扱わず、外部のサーバーにも送りません。取得の際は、1 件ずつ間隔を空け、拒否されたらその場で止まります。
